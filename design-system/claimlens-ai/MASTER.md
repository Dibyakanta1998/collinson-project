# ClaimLens AI Design System

Trust-oriented insurance operations interface. Provisional triage is always
labelled as non-final. Avoid generic AI purple gradients.

## Type

- IBM Plex Sans, 400/500/600/700
- Body 16px+, line-height 1.5
- Headings remain sentence case except eyebrow labels

## Colour

- Primary `#0369A1`
- Accent/protected `#16A34A`
- Background `#F0F9FF`
- Foreground `#0C4A6E`
- Card `#FFFFFF`
- Border `#BAE6FD`
- Destructive `#DC2626`
- Muted text `#475569`

## Interaction

- Visible 3px focus rings
- Keyboard order matches visual order
- Linked error summary for invalid forms
- Reduced motion: no timeline animation
- Split workspace stacks below 960px
